# Security Policy

## Supported Versions

We release security updates and bug fixes for the current active release line.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

The Awaaz project team takes the security of our speech recognition software and models seriously.

If you believe you have discovered a vulnerability, security flaw, or privacy risk:

1. **Do NOT open a public GitHub issue**.
2. Email your findings confidentially to the maintainer at `paramveer@example.com`.
3. Please include:
   - Description of the vulnerability and its potential impact.
   - Minimal reproduction steps, proof-of-concept audio/input, or script.
   - Any proposed mitigations or remediations.

### Response Timeline
- **Initial Response**: Within 48 hours acknowledging receipt.
- **Triage & Assessment**: Within 7 business days.
- **Fix & Disclosure**: Coordinated release with a security advisory once patched.

## Model Safety & Bias Reporting

If you observe unacceptable bias, inappropriate token emission, or potential violation of the **Sacred-Text Policy (§1.5)**, please contact us directly or file an issue with the `model-behavior` label.
